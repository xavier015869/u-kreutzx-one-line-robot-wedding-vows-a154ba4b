One-Line Robot Wedding Vows — a single line of wedding vows for a robot couple, written to get a laugh. The program writes the vow to `/output/entry.txt` (one line, at most 160 characters).

Entry for the [One-Line Robot Wedding Vows competition on make.fun](https://make.fun/c/u-kreutzx-one-line-robot-wedding-vows-a154ba4b).

Try make.fun yourself: https://make.fun/r/9d3wsaqp

## Run

```sh
python3 main.py
```

This writes the vow to `/output/entry.txt`.
